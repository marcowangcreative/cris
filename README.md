# cris

Marco Wang’s monorepo of idea MVPs. Each idea lives in its own top-level folder, with its own `package.json`, so a folder can later be split into its own repo.

| Idea | Folder | Description | Status |
| --- | --- | --- | --- |
| Dynamic Pricing Engine | [`dynamic-pricing/`](dynamic-pricing/) | Internal revenue desk for Marco Wang Photography. Recommends a wedding quote for an open date. Marco approves it. Public prices and existing proposals stay put. | MVP |

## Add an idea

Create a new top-level folder with its own README and dependencies. Do not import from another idea’s folder. Update the table above when the idea is ready to run.
